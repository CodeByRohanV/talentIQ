# Network Migration Documentation: Localhost to IP

This document summarizes the changes made to transition the AssessHub platform from using `localhost` to using a specific local network IP (`172.16.10.140`). These changes enable the platform to be accessed from other devices on the same network.

## Summary of Changes

### 1. Backend Configuration (`server/`)

| File | Change Description |
| :--- | :--- |
| `.env` | Updated `CORS_ORIGIN` to include both `172.16.10.140` and `localhost` origins for ports 8081, 5173, and 8080. |
| `src/app.js` | Updated the hardcoded `allowedOrigins` fallback list to prioritize the local IP while retaining `localhost` support. |
| `src/config/database.js` | Changed the default `DB_HOST` from `localhost` to `172.16.10.140`. |
| `.env.example` | Updated template values for `CORS_ORIGIN` to reflect the new networking scheme. |
| `README.md` | Updated documentation for `DB_HOST`, `CORS_ORIGIN`, and server startup messages to use the local IP. |

### 2. Frontend Configuration (`frontend/`)

| File | Change Description |
| :--- | :--- |
| `.env` | Updated `VITE_API_URL` to `http://172.16.10.140:5000/api/`. Added a trailing slash to ensure correct API path resolution. |
| `.env.example` | Updated the environment template to use the new IP and added the trailing slash. |

## Important Details

### CORS Policy
The backend now explicitly allows requests from the following origins to prevent "CORS Preflight" errors:
- `http://172.16.10.140:8081` (Vite Default)
- `http://172.16.10.140:5173`
- `http://localhost:8081`
- `http://localhost:5173`

### API Endpoint Resolution
The `VITE_API_URL` was changed from `http://localhost:[port]/api` to `http://172.16.10.140:5000/api/`. 
**Note:** The trailing slash `/` at the end of the URL is required for frontend API calls to correctly append routes like `/auth/login`.

## Action Required

To ensure these changes take effect, you must **restart** both development servers:
1. **Stop** your terminal processes.
2. **Start Backend**: `npm run dev` (in the `server` directory).
3. **Start Frontend**: `npm run dev` (in the `frontend` directory).
